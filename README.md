# RAT
A Remote Access Trojan (RAT) builder I wrote, It's good to troll your friends.

DISCLAIMER: Use it for educational purposes only!

# Installation
 1. Download Java 11+. Most preferrably Java 15.
 2. Download .NET [link](https://dotnet.microsoft.com/en-us/)
 3. Run RactionX.exe

# Usage
If the builder opens in the top right corner click 'build' it will bring you to the builder gui, click network and put the IP you want it to use for the server. Then go to config and turn on your personal preferences (anti-vm, Discord webhook ect.) then click 'Finalize build' it will put the .exe in the Config --> Builds folder.
